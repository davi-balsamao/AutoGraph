# Como funciona a gráfica (ATUALMENTE):
- O cliente entra em contato pelo Whatsapp e pergunta quais os serviços e produtos que a gráfica possui. A recepcionista que faz o contato com o cliente, e como a gráfica tem vários produtos, sendo alguns deles como **panfletos, cartões de visitas, blocos, banners, lonas, apostilas, sacolas, entre outros**. Se o cliente procura algum desses produtos, a recepcionista precisa de uma série de informações para fazer a Ordem de Serviço (OS), e para facilitar a sua vida, ela criou mensagens prontas para facilitar a comunicação. Eu desenvolvedor consegui algumas delas, que estão abaixo: 

1. Para orçar **panfletos**, gentileza informar:
- Você tem a arte pronta?
- Deseja qual quantidade?
- Será qual tamanho?
- Só frente ou frente e verso?

2. Para orçar **cartão de visita**, gentileza informar:
- Você tem a arte pronta?
- Deseja qual quantidade?
- Será só frente ou frente e verso?
- Terá verniz total?
- Terá laminação fosca e verniz localizado? Se sim, só frente ou frente e verso?

3. Para orçar **blocos**, gentileza informar:
- Você tem a arte pronta?
- Deseja qual quantidade?
- Qual tamanho do bloco?
- Quantas vias?
- Papel autocopiativo? S/N
- Qual cor de impressão?
- Numerado? S/N

4. Para orçamento de **banner ou lona**, gentileza informar
-Você tem a arte pronta?
-Qual tamanho deseja?

5. Para orçamento de **apostila**, gentileza informar:
- Tamanho A4?
- Quantas páginas 
- Só frente ou frente e verso 
- Colorida ou preto
- Encadernada com espiral?

Com os dados preenchidos, ela fala o preço e se o cliente aprovar, a OS vai para o setor correspondente de produção. 

# Como funcionaria a gráfica (depois do projeto concluído):
- O cliente entraria em contato com a gráfica pelo Whatsapp, so que invés da recepcionista fazer todo o contato inicial, isso será feito por um agente. Ele vai apresentar os produtos e serviços da gráfica, obter as informações necessárias para a OS, preenche-la quase que por completo, e gerar uma notificação no App na conta da Recepcionista para aprovação da OS. A recepcionista vai analisar e assumir a conversa finalizando a negociação com preços e etc. Quando a recepcionista fechar a OS, será sinalizado para o agente enviar um link com os dados de login para app da grafica em que o cliente ira acompanhar o seu pedido, e quando o pedido estiver concluido, o agente que vai notificar o cliente para busca-lo. 

## Algumas dificuldades que poderão surgir
- A gráfica nao produz arte, então depende do envio da arte pelo cliente, e muitas vezes o cliente não envia em um formato adequado, ou envia em baixa resolução, precisaremos tratar isso. 
- A gráfica nao tem um catalogo de preços uma vez que cada pedido pode variar bastante, então o agente nao deve ser capaz de informar preço algum, deve ser feito o chamado da recepcionista para isso.
