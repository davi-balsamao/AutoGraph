# [Testes] QA End-to-End (E2E) Completo

## 📖 Descrição
O teste final "Caminho Feliz" que garante que o App, o Backend e a Meta estão falando a mesma língua. Serve como ensaio para a apresentação do projeto.

## ✅ Critérios de Aceite (Definition of Done)
- [ ] Cliente fala no Zap e é atendido pelo robô RAG.
- [ ] IA coleta dados para a OS de um produto e despede-se.
- [ ] App Flutter em outro celular/emulador da recepcionista lista a nova OS.
- [ ] Recepcionista clica em Copiar Mensagem e joga o texto num Zap simulado do negócio.

## 🛠️ Checklist de Tarefas Técnicas
- [ ] Apagar DB/Conversas antigas do número de teste.
- [ ] Compilar Flutter apontando pra URL do backend em nuvem.
- [ ] Rodar o fluxo pelo menos 3 vezes com produtos diferentes (Cartão, Lona, Panfleto).
