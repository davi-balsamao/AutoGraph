# [Frontend] Inicialização do Projeto Flutter (Monorepo)

## 📖 Descrição
A última parte do Milestone 1 é preparar o terreno do front-end. Utilizaremos o Flutter para gerar aplicações tanto para o Cliente quanto para o Gerente da gráfica. O objetivo é criar o repositório inicial, organizar as pastas segundo os princípios do README e garantir que o App faça seu primeiro build com sucesso.

## ✅ Critérios de Aceite (Definition of Done)
- [ ] Projeto base do Flutter criado na pasta `/frontend`.
- [ ] Organização estrutural criada dentro de `lib/`: pastas `core`, `features/auth`, `features/os_cliente`, `features/admin_grafica`.
- [ ] Remoção dos comentários e código padrão do `counter app` gerado pelo `flutter create`.
- [ ] Projeto roda perfeitamente em emulador (Android ou iOS) ou web sem erros de compilação.
- [ ] Arquivo `pubspec.yaml` organizado com eventuais dependências de ambiente inicial.

## 🛠️ Checklist de Tarefas Técnicas
- [ ] Navegar até a raiz e executar `flutter create frontend`.
- [ ] Criar a hierarquia de pastas detalhada no README.
- [ ] Refatorar o `main.dart` para renderizar apenas um `MaterialApp` vazio com uma tela de "Hello World".
- [ ] Executar o `flutter run` no emulador e validar.
- [ ] Comitar o projeto base no repositório.
