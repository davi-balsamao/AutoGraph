Este arquivo serve para identificar onde voce deve colocar os cards que serão gerados, deve ser nessa pasta /docs/cards/

Os cards devem ser criados em formato markdown e devem seguir a estrutura abaixo:
- card[number].md
- number é um número inteiro incremental que começa em 1
- card1.md é o primeiro card
- card2.md é o segundo card
- e assim por diante
- card0.md é apenas uma ajuda para identificar onde os cards devem ser colocados, ele não deve ser usado como card
- os cards devem seguir o modelo de @Edtech_Métodos Ágeis_Cards.pdf
