# [Frontend] Setup Flutter e Estrutura de Autenticação Mínima

## 📖 Descrição
Início do app Flutter que servirá como Dashboard Admin da Gráfica. O foco inicial é configurar a estrutura básica do projeto e garantir uma tela de login (mesmo que mockada) para que a recepcionista acesse o painel de ordens de serviço.

## ✅ Critérios de Aceite (Definition of Done)
- [ ] Projeto Flutter inicializado (versão atualizada).
- [ ] Tela de Login implementada.
- [ ] Após o login, redirecionamento para a rota inicial do Dashboard.

## 🛠️ Checklist de Tarefas Técnicas
- [ ] Executar `flutter create`.
- [ ] Adicionar pacotes essenciais (`dio` ou `http`, gerência de estado).
- [ ] Desenhar UI básica do login (E-mail e Senha).
- [ ] Implementar regra de autenticação (pode ser hardcoded "admin/admin" para o MVP).
