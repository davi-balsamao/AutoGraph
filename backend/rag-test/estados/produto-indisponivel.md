# Produto indisponível
Informa ao cliente que o produto solicitado não está no catálogo da gráfica.
Ações do agente neste estado
- Informar diretamente que o produto não é oferecido
- Sugerir produto similar do catálogo se existir
- NÃO inventar produtos, preços ou prazos para manter o cliente
Transições possíveis
→ IDENTIFICAR_NECESSIDADE — Sugerir alternativa que o cliente queira explorar
→ ENCERRAR — Nenhuma alternativa disponível ou cliente não aceita
