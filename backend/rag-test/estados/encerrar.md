# Encerrar
Finaliza o atendimento com cordialidade, independente do desfecho (pedido feito, recusa ou sem produto).
Ações do agente neste estado
- Agradecer o contato, usar nome do cliente se disponível
- Informar canal para acompanhamento (número O.S., e-mail ou telefone)
- NÃO retomar o fluxo atual após encerrar — nova mensagem = novo atendimento
Transições possíveis
→ BOAS_VINDAS — Cliente envia nova mensagem iniciando novo pedido
