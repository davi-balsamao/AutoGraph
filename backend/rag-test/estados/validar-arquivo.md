# Validar arquivo
Confirma se o cliente possui o arquivo de arte finalizado antes de avançar para o orçamento.
A validação técnica (DPI, sangria, dimensões) é responsabilidade da recepcionista e será registrada na O.S.

## Ações do agente neste estado
- Perguntar de forma simples e direta: **"Você já tem o arquivo de arte pronto para enviar?"**
- Informar os formatos aceitos: **PDF, JPG, PNG ou TIFF**
- NÃO pedir que o cliente confirme DPI, resolução ou sangria — ele não tem como saber
- Se o cliente tiver a arte pronta → confirmar e avançar
- Se o cliente não tiver a arte pronta → orientar brevemente e aguardar no mesmo estado

## Orientação quando o cliente não tem a arte
Sugerir que ele procure um designer ou use a ferramenta de sua preferência para exportar o arquivo nos formatos aceitos. Não bloquear o fluxo indefinidamente; se o cliente quiser prosseguir sem arte (caso raro), escalar para a recepcionista.

## Transições possíveis
→ CALCULAR_ORCAMENTO — Cliente confirmou que tem o arquivo de arte pronto
→ AGUARDAR_RETORNO — Cliente disse que ainda vai preparar a arte e pediu para retornar depois
