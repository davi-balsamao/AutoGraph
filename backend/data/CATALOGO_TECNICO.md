# Catálogo de Produtos e Triagem - AutoGraph

Este documento é a única fonte de verdade para os produtos da gráfica.

## 1. Panfletos (Flyers/Folhetos)
**Descrição:** Material impresso para divulgação.
**Perguntas obrigatórias para o orçamento:**
1. Você tem a arte pronta?
2. Qual a quantidade? (Ex: 1000, 2500, 5000 unidades)
3. Qual o tamanho? (Ex: 10x14cm, 15x21cm)
4. É só frente ou frente e verso?

## 2. Cartão de Visita
**Descrição:** Cartões profissionais.
**Perguntas obrigatórias para o orçamento:**
1. Você tem a arte pronta?
2. Qual a quantidade? (Ex: 100, 500, 1000 unidades)
3. É só frente ou frente e verso?
4. Qual o acabamento? (Verniz Total ou Laminação Fosca com Verniz Localizado?)

## 3. Blocos (Talões/Receituários)
**Descrição:** Blocos numerados ou simples.
**Perguntas obrigatórias para o orçamento:**
1. Você tem a arte pronta?
2. Qual a quantidade de blocos?
3. Qual o tamanho? (Ex: A4, A5, 10x15cm)
4. Quantas vias por folha? (Ex: 1 via, 2 vias autocopiativo)
5. A impressão é colorida ou preto e branco?
6. O bloco é numerado?

## 4. Banner ou Lona
**Descrição:** Impressão em grande formato.
**Perguntas obrigatórias para o orçamento:**
1. Você tem a arte pronta?
2. Qual a largura e a altura? (Tamanho exato)

## 5. Apostila
**Descrição:** Impressão e encadernação de manuais/livros.
**Perguntas obrigatórias para o orçamento:**
1. O tamanho é A4?
2. Quantas páginas tem o arquivo?
3. É só frente ou frente e verso?
4. A impressão é colorida ou preto e branco?
5. A encadernação é com espiral?
