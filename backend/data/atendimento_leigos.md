# Guia de Atendimento para Leigos: Tradução de Jargões Gráficos

## Tradução de Jargões (O Cliente x A Gráfica)

| O que o cliente fala | O termo técnico exato |
| :--- | :--- |
| **"Colorido dos dois lados"** | **4x4** (Quatro cores frente e verso) |
| **"Letra brilhante"** ou **"Relevo"** | **Verniz Localizado** (ou Hot Stamping) |
| **"Papel durinho"** ou **"Grosso"** | **Couché 300g** (ou gramatura superior) |
| **"Adesivo que não rasga"** ou **"Pode molhar"** | **Adesivo Vinil** |
| **"Arte até a borda"** ou **"Sem margem branca"** | **Sangria** |
| **"Papel sem brilho"** ou **"Fosco"** | **Couché Fosco** (ou Laminação Fosca) |
| **"Corte com formato diferente"** | **Faca Especial** (ou Corte Especial) |
| **"Livro com a lombada reta"** | **Lombada Quadrada** (Brochura PUR/EVA) |
| **"Marca da dobra sem quebrar a tinta"** | **Vinco** |

## Como Confirmar Sem Soar Arrogante

A regra de ouro é **validar o benefício visual ou tátil**, não empurrar o termo técnico como uma correção. O cliente quer a garantia de que o resultado final será igual ao que ele imaginou, ele não quer uma aula de artes gráficas.

### Estratégias de Abordagem

* **Técnica da Confirmação Visual:** Sempre que possível, **mostre um exemplo físico** e amarre ao jargão. 
  * *Exemplo:* "Perfeito. Para ficar com essa letra brilhante que você pediu, nós usamos o que chamamos de Verniz Localizado. É exatamente igual a este cartão aqui, veja como destaca."
* **Adoção do Sanduíche de Vocabulário:** Comece com a palavra do cliente, insira o termo técnico no meio e feche com o benefício. 
  * *Exemplo:* "Você pediu o **papel mais durinho** *(cliente)*, então vou colocar no orçamento o papel **Couché 300g** *(técnico)* para garantir que seu material fique bem **firme e premium** *(benefício)*."
* **Eliminação da Correção Direta:** Nunca diga *"Ah, você quer dizer X"*. Eduque enquanto concorda. 
  * *Exemplo:* "Entendi perfeitamente, você quer colorido dos dois lados. Aqui na produção nós chamamos isso de **impressão 4x4**. Vou registrar exatamente assim no seu pedido para a máquina puxar as cores da frente e do verso corretamente."
* **Perguntas de Fechamento Direcionadas (O problema da Sangria):** Não use o jargão para perguntar, use para explicar o motivo de uma trava no pedido. Se o cliente enviar o arquivo errado, não pergunte *"O arquivo tem sangria?"*.
  * *Faça assim:* "Você quer que a cor vá até o **limite exato do papel** ou prefere uma **bordinha branca** como moldura? Se for até o limite, a gente precisa que você adicione a **sangria** no arquivo — que é basicamente uma sobra de arte para a guilhotina não deixar falhas no corte."
